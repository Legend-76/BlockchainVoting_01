# 区块链去中心化投票系统 (BlockchainVoting_01)

> 课程开源实践：基于 Solidity 智能合约的极简、透明、防篡改的链上投票工具。

本项目旨在利用区块链“不可篡改”和“去中心化”的特性，解决传统电子投票系统中可能存在的后台暗箱操作、数据被篡改以及透明度低等痛点。所有投票记录均通过智能合约上链，任何人都可以实时审计投票结果。

无需搭建本地环境，直接通过浏览器使用 Remix IDE 即可完成编译、部署与交互测试。

## 核心功能特性

智能合约提供了一套完整的投票生命周期管理功能：

| 模块 | 功能说明 |
| :--- | :--- |
| 初始化 | 部署合约时，可传入目标众筹金额或候选人列表（当前版本以字符串代表候选人）。 |
| 投票行为 | 投票者调用 vote 函数，输入候选人名称即可完成投票。 |
| 防刷票机制 | 基于 msg.sender 的以太坊地址进行校验，**每个钱包地址只能投票一次**，有效防止恶意刷票。 |
| 结果查询 | 任何人都可以通过 getVotes 函数，公开、透明地查询任意候选人的当前得票数。 |

### 安全与隐私
- **数据不可篡改**：一旦投票交易被区块确认，任何中心化机构都无法修改投票记录。
- **公开可审计**：所有交易记录公开在区块链浏览器上，确保流程100%透明。

## 技术栈与架构

本项目极度轻量，0 第三方依赖，无需 npm 安装，无需打包。

| 层次 | 选型 | 说明 |
| :--- | :--- | :--- |
| 智能合约语言 | Solidity `^0.8.0` | 运行于以太坊虚拟机（EVM） |
| 开发与测试环境 | Remix IDE | 浏览器端一站式智能合约开发工具 |
| 核心数据结构 | `mapping` | 用于记录候选人得票数及地址投票状态 |
| 安全校验 | `require` | 断言机制，防止重复投票等非法操作 |

快速开始 (如何运行)
本项目不需要在本地安装任何环境，只需打开浏览器即可运行：

访问 Remix IDE。

在左侧 contracts 文件夹下新建一个文件，命名为 Voting.sol。

将本仓库中的 Voting.sol 源码复制并粘贴进去。

在左侧菜单栏点击 Solidity Compiler，点击 Compile Voting.sol 按钮完成编译。

切换到 Deploy & Run Transactions 菜单，点击橙色的 Deploy 按钮部署合约。

在下方部署好的合约面板中，在 vote 旁边的输入框填入名字，点击 vote 即可完成一次投票。
